# Third-party assets

The frontend bundles Lucide React icons locally. No remote icon/font/image requests or telemetry are configured. System typography uses fonts already installed on the device.

Lucide uses the ISC license. Its notice is retained in [licenses/lucide.txt](licenses/lucide.txt). The exact installed package is pinned in package.json and pnpm-lock.yaml. The original app favicon is project-authored.
